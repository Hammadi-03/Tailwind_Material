🦶 Step 6: Footer

The footer is the closing part of a website. It usually contains additional navigation, contact info, social links, and copyright.

6.2 Class Explanation

📊 Grid Layout

ClassFunction
grid-cols-2 lg:grid-cols-42 columns mobile, 4 columns desktop
col-span-2 lg:col-span-1About section: 2 columns on mobile, 1 on desktop
gap-8 lg:gap-12Wider gap on desktop

⚪ Opacity for Light Colors on Dark BG

ClassFunction
text-white/70White text with 70% opacity
bg-white/10White background with 10% opacity
border-white/10White border with 10% opacity
text-white/60Copyright text more subtle

📐 Utility Classes

ClassFunction
space-y-3Vertical spacing 0.75rem between list items
shrink-0Icon does not shrink in flex
mt-0.5Margin top 2px (align icon with text)

6.3 CSS for Footer

style.css 
.footer {
    background-color: #3D3D3D; /* Dark background */
    color: white;
}

.footer a {
    color: rgba(255, 255, 255, 0.7);
    text-decoration: none;
    transition: color 0.3s ease;
}

.footer a:hover {
    color: white;
}
