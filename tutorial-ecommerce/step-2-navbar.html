2.3 Tailwind Class Explanation

📍 Positioning (Header Fixed)

ClassFunction
fixedFixed position, navbar remains visible during scroll
top-0 left-0 right-0Stick to top, left, and right of the screen
z-50Z-index 50, so navbar is always in front

📦 Container & Spacing

ClassFunction
max-w-7xlMaximum width 80rem (1280px)
mx-autoHorizontal margin auto (center)
px-4 sm:px-6 lg:px-8Responsive horizontal padding
h-14 lg:h-16Height 3.5rem (mobile) → 4rem (desktop)

🔧 Flexbox Layout

ClassFunction
flexEnable flexbox
items-centerAlign items vertically to the center
justify-betweenSpace between (logo left, nav center, icons right)
gap-2 / gap-8Spacing between flex items

📱 Responsive Classes

ClassFunction
hidden sm:blockHidden on mobile, appears at ≥640px
hidden lg:flexNav links hidden until ≥1024px
lg:hiddenHamburger menu only below 1024px

2.4 Custom CSS for Navbar

Some styling cannot be done with Tailwind alone, we need custom CSS:

style.css 
/* Glassmorphism effect */
.navbar {
    backdrop-filter: blur(10px);
    background-color: rgba(255, 255, 255, 0.95);
    transition: all 0.3s ease;
}

/* Shadow on scroll (via JavaScript) */
.navbar.scrolled {
    box-shadow: 0 2px 20px rgba(0, 0, 0, 0.1);
}

/* Nav link dengan animated underline */
.nav-link {
    position: relative;
    color: var(--color-text);
    font-weight: 500;
    padding: 0.5rem 0;
    transition: color 0.3s ease;
}

.nav-link::after {
    content: '';
    position: absolute;
    bottom: 0;
    left: 0;
    width: 0;
    height: 2px;
    background-color: var(--color-primary);
    transition: width 0.3s ease;
}

.nav-link:hover::after,
.nav-link.active::after {
    width: 100%;
}

/* Cart Badge */
.cart-badge {
    position: absolute;
    top: -8px;
    right: -8px;
    width: 20px;
    height: 20px;
    background-color: var(--color-accent);
    color: white;
    border-radius: 50%;
    display: flex;
    align-items: center;
    justify-content: center;
    font-size: 0.75rem;
    font-weight: 600;
}
💡 Glassmorphism

backdrop-filter: blur(10px) + semi-transparent background = modern frosted glass effect. Content behind the navbar will look blurry!
