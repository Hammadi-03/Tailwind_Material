🦸 Step 3: Hero Section

Hero section adalah area banner utama yang pertama dilihat pengunjung. Ini adalah kesempatan untuk membuat first impression yang kuat!

3.1 Hero Section Structure

The hero section uses a 2-column grid: text content on the left, an image on the right.

3.2 Key Class Explanations

📐 Grid Layout

ClassFunction
gridEnable CSS Grid
lg:grid-cols-22 columns on large screens (≥1024px)
gap-8 lg:gap-12Gap between columns (2rem → 3rem)
items-centerVertical alignment center

📏 Sizing & Spacing

ClassFunction
pt-20 lg:pt-24Padding top for fixed navbar (5rem → 6rem)
aspect-[4/5]Custom aspect ratio 4:5 (portrait)
max-h-[450px]Maximum height 450px
max-w-lgMax-width for paragraphs to ensure readability

🎨 Styling Classes

ClassFunction
bg-primary/10Primary background with 10% opacity
rounded-fullPill-shaped border radius (badge)
rounded-2xl1rem border radius
shadow-xlExtra large box shadow
leading-tightLine-height 1.25 (for headings)

🎯 Positioning Floating Elements

ClassFunction
relativeParent container for absolute children
absoluteAbsolute position for badge
-bottom-4 -left-4Negative position (outside of container)
-bottom-4 -left-4Negative position in top right corner
💡 Pro Tip: Negative Positioning

Classes like -bottom-4 use negative values to make elements "pop out" from the parent container, creating an attractive floating effect!

3.3 Custom CSS untuk Hero

style.css 
/* Gradient Background */
.hero-gradient {
    background: linear-gradient(135deg, var(--color-secondary) 0%, var(--color-white) 100%);
}

/* Subtle Pattern Overlay */
.hero-pattern {
    background-image: url("data:image/svg+xml,%3Csvg width='60' height='60' ...");
}

/* Button Primary */
.btn-primary {
    background-color: var(--color-primary);
    color: white;
    padding: 0.75rem 1.5rem;
    border-radius: 0.5rem;
    font-weight: 500;
    transition: all 0.3s ease;
}

.btn-primary:hover {
    background-color: var(--color-primary-dark);
    transform: translateY(-2px);
    box-shadow: 0 4px 12px rgba(92, 110, 78, 0.3);
}

/* Secondary Button (Outline) */
.btn-secondary {
    background: transparent;
    color: var(--color-primary);
    padding: 0.75rem 1.5rem;
    border: 2px solid var(--color-primary);
    border-radius: 0.5rem;
}

.btn-secondary:hover {
    background-color: var(--color-primary);
    color: white;
}

/* Fade In Up Animation */
@keyframes fadeInUp {
    from {
        opacity: 0;
        transform: translateY(20px);
    }
    to {
        opacity: 1;
        transform: translateY(0);
    }
}

.animate-fade-in-up {
    animation: fadeInUp 0.6s ease forwards;
}

.delay-200 {
    animation-delay: 0.2s;
}

3.4 Responsive Behavior

ScreenBehavior
Mobile (default)1 column, centered text, buttons stack vertically
Tablet (sm)Floating badges appear, buttons side-by-side
Desktop (lg)2 columns, text left-aligned
Large (xl)Larger font size
