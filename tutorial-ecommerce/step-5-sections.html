📦 Step 5: Other Sections

Besides Hero and Products, there are other sections that complete the main page: Categories, Promo Banner, Benefits, and Newsletter.

5.1 Categories Section

Displays product categories in a responsive grid:

categories.html 
<!-- Categories Section -->
<section class="py-12 lg:py-16 bg-white">
    <div class="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8">
        <!-- Header -->
        <div class="text-center mb-8">
            <h2 class="font-playfair text-2xl lg:text-3xl font-bold text-custom-text mb-3">
                Product Categories
            </h2>
            <p class="text-text-light max-w-2xl mx-auto">
                Find various Muslim fashion choices for your needs
            </p>
        </div>

        <!-- Grid: 2 cols (mobile) → 5 cols (desktop) -->
        <div class="grid grid-cols-2 md:grid-cols-3 lg:grid-cols-5 gap-4 lg:gap-6">
            
            <!-- Category Card -->
            <a href="products.html?category=gamis" class="category-card group">
                <div class="w-12 h-12 mx-auto mb-3 bg-primary/10 rounded-full 
                            flex items-center justify-center category-icon">
                    <svg class="w-6 h-6 text-primary">...</svg>
                </div>
                <h3 class="font-medium text-custom-text group-hover:text-primary transition">
                    Gamis
                </h3>
                <p class="text-sm text-text-light mt-1">120+ Products</p>
            </a>
            
        </div>
    </div>
</section>
💡 Group Hover

group + group-hover: allows us to change the style of child elements when the parent is hovered. Example: when the card is hovered, the text changes color!

📋 Form Styling

style.css 
.form-input {
    width: 100%;
    padding: 0.75rem 1rem;
    border: 1px solid var(--color-border);
    border-radius: 0.5rem;
    transition: all 0.3s ease;
    background-color: white;
}

.form-input:focus {
    outline: none;
    border-color: var(--color-primary);
    box-shadow: 0 0 0 3px rgba(92, 110, 78, 0.1);
}
ℹ️ Class flex-1

flex-1 makes the input take up the remaining space in the flex container, while the button stays compact with whitespace-nowrap.
