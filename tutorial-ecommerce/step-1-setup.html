📦 Step 1: Setup Project

Langkah pertama adalah menyiapkan environment untuk membangun tampilan E-Commerce kita menggunakan Tailwind CSS.

1.1 Project File Structure

Heres the folder structure we will create:

folder-structure 
ecommerce/
├── index.html          ← Main page
├── products.html       ← Product list page
├── product-detail.html ← Product detail page
├── cart.html           ← Cart page
├── checkout.html       ← Checkout page
├── about.html          ← About us page
└── assets/
    ├── css/
    │   └── style.css   ← Additional custom CSS
    └── js/
        └── main.js     ← JavaScript

1.2 Basic HTML Boilerplate with Tailwind CDN

We will use Tailwind CSS via CDN as it's the fastest way for prototyping. Here is the basic template we'll use:

index.html 
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Muslim Fashion Indonesia</title>
    
    <!-- Tailwind CSS CDN -->
    <script src="https://cdn.tailwindcss.com"></script>
    
    <!-- Google Fonts -->
    <link rel="preconnect" href="https://fonts.googleapis.com">
    <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
    <link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=Playfair+Display:wght@400;500;600;700&display=swap" rel="stylesheet">
    
    <!-- Custom CSS -->
    <link rel="stylesheet" href="assets/css/style.css">
</head>
<body class="font-inter bg-background">

    <!-- Website content will go here -->

    <script src="assets/js/main.js"></script>
</body>
</html>
ℹ️ Info

<script src="https://cdn.tailwindcss.com"> is the fastest way to use Tailwind. For production, installing via npm is recommended for file size optimization.

1.3 Custom Tailwind Configuration

This project uses custom colors and fonts. Configuration is done directly in HTML with a script:

Tailwind Config (inside <head>) 
<script>
    tailwind.config = {
        theme: {
            extend: {
                // Custom Colors - Olive/Sage Theme
                colors: {
                    primary: '#5C6E4E',        // Main Olive green
                    'primary-dark': '#4A5A3E', // For hover state
                    'primary-light': '#7A8F6A',
                    secondary: '#F5F0E6',      // Soft Cream
                    accent: '#8B7355',         // Warm Brown
                    'accent-dark': '#6B5A45',
                    background: '#FAFAF7',     // Off-white
                    'custom-text': '#3D3D3D',  // Dark gray
                    'text-light': '#6B6B6B',
                    'custom-border': '#E5E0D5',
                    gold: '#C4A962',           // For ratings
                },
                // Custom Fonts
                fontFamily: {
                    'playfair': ['Playfair Display', 'serif'],
                    'inter': ['Inter', 'sans-serif'],
                }
            }
        }
    }
</script>
💡 Color Explanation

Olive/Sage green was chosen as it gives a natural, elegant, and modest feel - perfect for a Muslim fashion brand!

1.4 Typography: Font Pairing

This project uses a combination of 2 fonts that complement each other:

Font Tipe Penggunaan Class Tailwind
Playfair Display Serif Heading, Logo, Judul font-playfair
Inter Sans-serif Body text, Deskripsi font-inter

1.5 Using Classes on the Body

Notice the classes being used on the <body> tag:

Body Tag 
<body class="font-inter bg-background">
Class Fungsi
font-inter Set default font seluruh halaman ke Inter (dari custom config)
bg-background Background off-white #FAFAF7 (dari custom config)
